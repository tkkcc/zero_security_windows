# 界面文案规则

面向公开发行的中英文界面。功能文案不描述某台电脑、开发过程或旧版修复经过。

## 信息分区

| 位置 | 内容 |
| --- | --- |
| 右侧状态列 | 当前状态的简短标签，不附重试提示、日期、计数或错误信息 |
| 底部功能 | 执行目标；说明会调整什么 |
| 底部影响 | 必要的范围和限制，如打印到 PDF 不可用、64 位 DEP 强制保留 |
| 底部状态 | 检测结果；日期、数量、具体对象和运行时状态放在这里 |
| 底部操作 | 当前可用的下一步；执行中不提示尚不可用的快捷键 |
| 底部错误、日志 | 执行失败的具体原因和完整记录位置；读取受限的原始信息保存在检测日志 |

说明换行后与正文对齐。详情按内容调整高度，列表保留选中项可见。长错误保留操作和日志入口，并提示完整错误的记录位置。

## 状态含义

| 标签 | 含义 |
| --- | --- |
| 待检测 | 尚未读取当前设置 |
| 检测中 | 正在读取设置，没有执行更改 |
| 未安装、已安装 | 应用的当前安装状态；结合安装或卸载类别理解目标 |
| 待设置、待禁用、待关闭、待清理 | 当前配置尚未完全符合该项目目标 |
| 已设置、已禁用、已关闭、无固定项 | 检测结果已符合该项目目标 |
| Windows 10、Windows 11 | 当前右键菜单样式，可以继续切换 |
| 等待执行 | 已加入执行队列，尚未开始执行 |
| 执行中 | 正在安装、卸载或应用设置 |
| 待安全模式 | 已加入安全模式执行队列 |
| 待正常模式 | 当前处于安全模式，该项目需要正常模式 |
| 待重启 | 更改已保存，本次启动尚未生效 |
| 待重新登录 | 更改已保存，当前登录会话的界面尚未更新 |
| 部分防护保留 | 可配置设置已关闭，实际运行的系统或程序仍有防护；详情列出具体结果 |
| 未运行 | Defender 未运行，因此篡改防护实时状态不可用 |
| 无需处理 | 功能在当前环境不可用，或没有可处理的对象 |
| 状态待确认 | Windows 暂未提供可用结果，可以重新检测 |
| 读取受限 | Windows 限制了状态读取，可以重新检测 |
| 执行未完成 | 实际执行发生错误，可以重试 |

读取失败和执行失败分别显示。未知状态不推断为已启用或已关闭；运行时保留防护不推断为全部禁用。安全机制的设置、运行时状态和生效操作分别说明。

## 逐项校对范围

143 项中英文功能说明均已对照目录中的执行操作和检测逻辑校对。安装项说明应用用途；卸载项明确移除对象；桌面项写出目标值；服务项说明被停用的后台能力；安全项区分可配置部分和实际运行防护。

更新到期日、任务栏固定应用、SysMain 内存状态、LSA、DEP、驱动签名和程序防护分别核对详情呈现。程序防护使用中文名称和带单位含义的进程计数，多个计数可能包含同一进程。

临时本机恢复和诊断脚本保存在忽略的 artifacts 目录，不进入功能目录或公开产品界面。
