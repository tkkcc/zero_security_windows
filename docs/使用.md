# 使用指南

## 开始与操作

[下载 EXE](https://github.com/tkkcc/zero_security_windows/releases/latest/download/zero_security_windows.exe)，双击打开并允许管理员权限。无需安装或额外运行库。

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓ | 选择项目 |
| Space | 执行当前可用项、重试或重新检测 |
| A | 执行全部可用项 |
| R | 在提示需要重启时重启 |
| Q | 退出 |

快捷键不区分大小写；鼠标只选择项目。右侧显示当前状态，底部说明功能、影响、检测结果和可用操作。具体设置范围以程序中的说明为准。

## 执行与结果

按提示重启或重新登录。程序会在重启后继续；手动启动不会自动重启，自动续跑的倒计时可按任意键取消。

“可”表示有可用操作；“排队中”和“执行中”表示进度。完成状态表示该项目达到可配置目标，系统限制与实际运行情况在底部说明。

“已跳过”表示 Windows 限制访问；“状态待确认”可重新检测；“执行未完成”可重试。原因和日志入口显示在底部。

检测只读取设置。手动修改后，只有再次执行对应项目或执行全部才重新应用目标设置。

日志位于 `%ProgramData%\ZeroSecurityWindows`：`checks.jsonl` 为检测记录，`operations.jsonl` 为执行记录，`errors.log` 为程序错误。
