# 使用指南

[English](使用.en.md)

## 开始与操作

[下载 EXE](https://github.com/tkkcc/zero_security_windows/releases/latest/download/zero_security_windows.exe)，双击打开，允许管理员权限，按 **A** 执行全部。无需安装或额外运行库。

也可在命令提示符（cmd）中下载并运行：

```cmd
curl.exe -fL https://github.com/tkkcc/zero_security_windows/releases/latest/download/zero_security_windows.exe -o "%TEMP%\zero_security_windows.exe" && start "" /wait "%TEMP%\zero_security_windows.exe"
```

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓ | 选择项目 |
| Space | 执行可用项、重试未完成项或重新检测待确认项 |
| A | 执行全部可用项 |
| R | 在提示需要重启时重启 |
| Q | 退出 |

快捷键不区分大小写。鼠标点击、滚轮与拖动只选择项目。右键菜单样式可在 Windows 10 / 11 之间切换，其余项目按所列目标执行。

## 执行与重启

列表顺序固定，检测、失败和重试不会移动选中项。本地优化先于软件安装；依赖安装结果的输入法、桌面和开始菜单清理在安装后处理。单项失败不阻断无关项目。

按提示重启，程序会自动继续。安全模式可执行部分本地设置；安装、卸载及依赖正常模式组件的项目在返回正常模式后执行。需要重新登录的项目在注销并重新登录后更新状态。

手动启动不会自动重启。自动续跑时，按任意键可停止重启或关闭倒计时。重启次数取决于设置的生效条件及安装器要求。

## 状态与详情

右侧显示简短状态；选中项目后，底部分为**功能、影响、状态、操作**。日期、数量、具体对象和运行情况归入状态，失败原因与日志按需显示。

| 状态 | 含义与操作 |
| --- | --- |
| 待检测、检测中 | 尚未读取或正在读取设置 |
| 可安装、可卸载、可设置、可禁用、可关闭、可清理 | 有可用操作，按 Space 执行 |
| 排队中、执行中 | 已加入队列或正在执行 |
| 已安装、未安装、已设置、已禁用、已关闭、无固定项 | 已符合该项目目标 |
| 已优化 | 安全项目的可配置设置已达到目标，运行限制见底部 |
| Windows 10、Windows 11 | 当前右键菜单样式，按 Space 切换 |
| 待安全模式、待正常模式 | 需要切换到相应模式继续执行 |
| 待重启、待重新登录 | 更改已保存，需要重启或重新登录生效 |
| 无需处理 | 当前环境没有可处理的对象或功能不适用 |
| 已跳过 | Windows 限制访问；查看原因和日志，无需反复尝试 |
| 状态待确认 | 暂未获得可用结果，按 Space 重新检测 |
| 执行未完成 | 实际执行发生错误，按 Space 重试 |

“已优化”不表示所有进程的防护全部关闭。Windows 强制或程序自行启用的保护可能保留，例如 64 位程序的 DEP；底部会说明实际运行情况。防护后台已停用时，依赖它的提醒无需单独处理。

“任务栏固定图标”检测 Windows 保存的固定项，底部列出数量与名称。正在运行的窗口按钮不一定已固定。

日志目录为 `%ProgramData%\ZeroSecurityWindows`：`checks.jsonl` 记录检测问题，`operations.jsonl` 记录执行过程，`errors.log` 记录程序错误。

## 设置范围与手动调整

检测只读取设置。手动修改后，只有再次执行对应项目或执行全部才会重新应用目标设置。

| 范围 | 执行效果与调整入口 |
| --- | --- |
| 普通隐私、桌面、连接设置 | 保留 Windows 设置、控制面板或应用内的手动开关 |
| 位置 | 关闭位置访问及应用请求位置的通知，保留 Windows 设置中的开关 |
| Windows 更新、传递优化 | 长期暂停更新，只关闭设备间共享；保留更新页面、恢复更新及正常下载 |
| 系统还原 | 关闭各卷系统保护；可在“系统属性 → 系统保护”重新启用 |
| 系统休眠 | 关闭休眠并移除 hiberfil.sys，虚拟内存保留；可用管理员命令 `powercfg /hibernate on` 恢复 |
| 自动驱动更新、联网搜索 | 使用专门策略关闭，可通过本地组策略撤销；仍可手动安装驱动，商店组件保留 |
| 应用启动预读 | 关闭应用预读、预启动和记录；SysMain 保持自动启动，内存压缩与内存页合并保留系统设置 |
| 后台服务 | 诊断、跨设备、联系人数据、打印、设备发现和流量统计关闭后续启动；普通服务可在 services.msc 调整，每用户服务需恢复模板配置并重新登录 |
| 深度安全设置、应用卸载 | Defender 服务与驱动等不保证通过普通设置页面恢复；卸载的应用需要重新安装 |
| 通用通知 | 弹窗、声音、通知中心和角标交由 Windows 与各应用控制 |

时间同步、USB 即插即用、蓝牙、Wi-Fi 和推送服务保留。时间同步项目设为自动启动并运行，保留现有校时服务器配置。
