# User guide

[简体中文](使用.md)

## Get started and controls

[Download the EXE](https://github.com/tkkcc/zero_security_windows/releases/latest/download/zero_security_windows.exe), double-click it, allow administrator access and press **A** to run all. No installation or separate runtime is needed.

Or download and run it in Command Prompt (cmd):

```cmd
curl.exe -fL https://github.com/tkkcc/zero_security_windows/releases/latest/download/zero_security_windows.exe -o "%TEMP%\zero_security_windows.exe" && start "" /wait "%TEMP%\zero_security_windows.exe"
```

| Key | Action |
| --- | --- |
| ↑ / ↓ | Select an item |
| Space | Run an available item, retry an incomplete action or recheck an unconfirmed result |
| A | Run all available items |
| R | Restart when prompted |
| Q | Exit |

Keys are case insensitive. Mouse clicks, scrolling and dragging only select items. The context menu style switches between Windows 10 and 11; other items apply their stated targets.

## Execution and restart

Rows keep their positions during checks, failures and retries. Local optimizations run before installations; dependent input method, desktop and Start menu cleanup follows installation. A failed item does not block unrelated work.

Restart when prompted; the app continues automatically. Safe Mode supports some local settings. Installation, removal and items that depend on normal-mode components run after returning to normal mode. Items that need a new sign-in update their status after you sign out and back in.

Manual launches do not restart automatically. Press any key to stop a restart or exit countdown during automatic continuation. The number of restarts depends on settings and installer requirements.

## Status and details

The right column shows short labels. Select an item to see **Purpose, Effect, Status and Action** below the table. Dates, counts, affected objects and runtime results belong in Status; errors and logs appear when needed.

| Status | Meaning and action |
| --- | --- |
| Awaiting check, Checking | Settings have not been read yet or are being read |
| Can install, Can uninstall, Can configure, Can disable, Can turn off, Can clean up | An action is available; press Space to run it |
| Queued, Running | The item is queued or being executed |
| Installed, Not installed, Configured, Disabled, Off, No pins | The item meets its target |
| Optimized | Configurable security settings meet the target; runtime limits appear below |
| Windows 10, Windows 11 | Current context menu style; press Space to switch |
| Needs Safe Mode, Needs normal mode | Switch to the required mode to continue |
| Needs restart, Needs sign-in | Changes are saved and need a restart or a new sign-in to take effect |
| Not applicable | There is no object to process or the feature does not apply |
| Skipped | Windows restricts access; read the reason and log without repeated attempts |
| Unconfirmed | A usable result is temporarily unavailable; press Space to recheck |
| Incomplete | Execution failed; press Space to retry |

“Optimized” does not mean every process has all protections disabled. Windows-mandated or application-enabled protections may remain, such as DEP for 64-bit applications; runtime details explain these limits. When protection background services are disabled, dependent warnings need no separate action.

“Pinned taskbar apps” checks pins saved by Windows and lists their count and names below the table. A running window's taskbar button is not necessarily pinned.

Logs are stored in `%ProgramData%\ZeroSecurityWindows`: `checks.jsonl` records check diagnostics, `operations.jsonl` records execution, and `errors.log` records application errors.

## Scope and manual adjustments

Checks only read settings. After a manual change, the target settings are reapplied only when you run the corresponding item or run all.

| Scope | Effect and adjustment options |
| --- | --- |
| Ordinary privacy, desktop and connection settings | Controls remain available in Windows Settings, Control Panel or the application |
| Location | Turns off location access and location request notifications; Windows Settings controls remain available |
| Windows Update, Delivery Optimization | Pauses updates long term and disables peer sharing; the update page, resume controls and normal downloads remain available |
| System Restore | Turns off protection for all volumes; enable it again in System Properties → System Protection |
| Hibernation | Disables hibernation and removes hiberfil.sys; virtual memory is preserved. Restore with the administrator command `powercfg /hibernate on` |
| Automatic driver updates, online search | Disabled through dedicated policies that can be reverted in Local Group Policy; manual driver installation and Store components remain available |
| App launch preloading | Disables application prefetching, prelaunch and recording. SysMain starts automatically; memory compression and page combining retain Windows settings |
| Background services | Disables future startup for diagnostics, cross-device features, contact data, printing, device discovery and data usage. Ordinary services can be adjusted in services.msc; per-user services need template configuration restored and a new sign-in |
| Deep security settings, app removal | Defender services and drivers may require more than ordinary Settings controls to restore; removed applications must be reinstalled |
| General notifications | Toasts, sounds, notification center and badges remain controlled by Windows and individual applications |

Time synchronization, USB Plug and Play, Bluetooth, Wi-Fi and push services are preserved. The time synchronization item enables automatic startup and starts the service while preserving its time server configuration.
