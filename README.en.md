# Zero Security Windows

[简体中文](README.md)

A lightweight Windows optimization tool that brings system cleanup, desktop customization and software management into one interface, with individual actions and one-click optimization.

- **System cleanup**: Reduce security restrictions, telemetry, unnecessary background services and update activity.
- **Desktop customization**: Organize the taskbar, Start menu, input methods and power settings.
- **Software management**: Remove built-in apps and install everyday tools.
- **Clear feedback**: Chinese and English interfaces with live progress and results for each action.
