# Zero Security Windows

**更轻、更纯净的 Windows。**

Zero Security Windows 是一款开源 Windows 11 精简与优化工具，以性能为优先，减少系统防护开销、后台活动和预装内容。

[下载最新版](https://github.com/tkkcc/zero_security_windows/releases/latest/download/zero_security_windows.exe) · [反馈问题](https://github.com/tkkcc/zero_security_windows/issues)

## 功能特色

- **深度优化**：调整 Defender、核心隔离、漏洞防护及系统服务，处理常规设置之外的开销与运行限制。
- **彻底精简**：移除预装应用、Edge 及相关入口，关闭遥测、系统推广与不需要的后台功能。
- **装机配置**：集中调整桌面、任务栏和输入环境，安装日常与开发工具。
- **逐项恢复**：系统设置恢复为 Windows 默认可用配置，已移除的应用可重新安装。
