# Zero Security Windows

将 Defender 深度禁用、系统精简、桌面调整和软件安装串成一套自动续跑流程。单个 EXE，支持单项调整与一键执行。

- **自动处理安全模式**：自动安排进入安全模式，禁用 Defender 服务与驱动，再返回正常模式继续处理。
- **先优化，后安装**：先处理本地设置与后台精简，再并行安装常用工具。
- **减少系统负担**：调整安全限制、减少遥测与不需要的后台活动，清理内置应用。
- **整理桌面环境**：统一调整任务栏、开始菜单、输入法与电源设置。
- **进度清晰可见**：中英文界面，实时呈现每项检测结果、执行进度与后续操作。
