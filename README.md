# Zero Security Windows

Zero Security Windows 面向追求性能和自主控制的用户，帮助你得到更轻、更少限制的 Windows：减少软件拦截、预装负担和不必要的后台开销，让电脑专注于工作、开发与游戏。

深度精简也能省心完成。工具深入处理普通开关之外的安全限制，自动衔接所需的安全模式处理和重启续跑，例如 Defender 的深度禁用。每项更改的影响与结果清楚呈现，取舍由你决定。
