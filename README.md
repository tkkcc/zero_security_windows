# Zero Security Windows

Zero Security Windows 是一款 Windows 精简工具，让你运行软件时少被拦截，日常使用时少受后台拖累，把电脑留给真正要做的事。

工具自动处理安全模式中的 Defender 禁用，并在重启后继续完成调整，省去手动切换和反复设置的麻烦。每项更改的影响与结果清楚呈现，改什么由你决定。
